# rustmd Homebrew tap

[rustmd](https://github.com/riverzhou/rustmd) is a local-first notes app for Markdown, HTML, CSV, TXT and JSON (plain files, offline, no account).

```bash
brew tap riverzhou/tap
brew install --cask rustmd
```

The cask currently supports **Apple Silicon (arm64) macOS** and follows the latest GitHub release.

The cask lives in [`Casks/rustmd.rb`](Casks/rustmd.rb).
